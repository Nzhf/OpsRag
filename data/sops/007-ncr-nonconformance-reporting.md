# SOP: Non-Conformance Reporting and Material Review

**Document ID:** SOP-QA-005
**Version:** 1.4
**Effective Date:** 2024-08-15
**Department:** Quality Assurance
**Applies to:** All production areas, receiving, and finished goods
**Review Cycle:** Annual

## 1. Purpose

This procedure establishes the process for identifying, documenting, and dispositioning non-conforming materials and products at BizLink Penang Manufacturing. Effective non-conformance management prevents defective products from reaching customers and drives continuous improvement.

## 2. Scope

This SOP applies to:
- Incoming material rejects (IQC)
- In-process defects found during production
- Final inspection failures
- Customer returns (RMA)
- Supplier quality issues

## 3. Definitions

| Term | Definition |
|------|------------|
| Non-conformance | Product or material that does not meet specified requirements |
| NCR | Non-Conformance Report - formal documentation of defect |
| MRB | Material Review Board - cross-functional team for disposition decisions |
| SCAR | Supplier Corrective Action Request - formal request to supplier for root cause |
| Rework | Correcting non-conformance to meet specification |
| Scrap | Material is unusable and must be disposed |
| Use-As-Is | Material deviates from spec but is acceptable for use |
| Return to Supplier | Reject incoming material, return for credit or replacement |

## 4. Responsibilities

| Role | Responsibility |
|------|----------------|
| Any Employee | Identify and report non-conformances |
| Quality Inspector | Verify defect, initiate NCR, recommend disposition |
| Quality Engineer | Investigate root cause, coordinate MRB for complex cases |
| Production Supervisor | Implement containment, assign rework resources |
| Quality Manager | Approve Use-As-Is dispositions, sign off high-value scrap |
| MRB | Review borderline cases, approve non-standard dispositions |

## 5. Non-Conformance Identification

### 5.1 Detection Points

| Detection Point | Common Non-Conformances | Initiator |
|-----------------|------------------------|-----------|
| Incoming Inspection (IQC) | Wrong part, dimensional failure, documentation missing | IQC Inspector |
| SMT Production | Solder defects, missing/wrong components | AOI, Visual Inspector |
| Assembly | Missing hardware, assembly errors | Operator, Inspector |
| Functional Test | Electrical failure, performance out of spec | Test Operator |
| Final Inspection | Cosmetic defects, documentation incomplete | QA Inspector |
| Customer Return | Field failure, DOA | Customer Service |

### 5.2 Initial Response

When non-conformance is identified:
1. Stop processing the affected material/product
2. Apply red "HOLD" tag with:
   - Date
   - Defect description
   - Inspector/Operator ID
   - Quantity affected
3. Segregate from conforming material
4. Notify Production Supervisor and Quality Inspector within 1 hour

## 6. Non-Conformance Report (NCR) Process

### 6.1 Initiating NCR

Complete NCR Form (NCR-001) with:

**Section A - Identification:**
- NCR number (auto-generated by ERP: NCR-YYYY-NNNN)
- Date identified
- Part number and description
- Quantity affected
- Lot/batch number
- Location detected (line, station)
- Customer/PO reference (if applicable)

**Section B - Defect Description:**
- Detailed description of non-conformance
- How defect was detected (visual, test, measurement)
- Reference to applicable specification/drawing
- Photos attached (required for all NCRs)
- Sample retained (location)

**Section C - Containment:**
- Immediate containment actions taken
- Quantity segregated
- Additional inspection of suspect lots (upstream/downstream)
- Notification to affected areas

### 6.2 Root Cause Analysis

For recurring defects or significant impact:

Quality Engineer leads 5-Why or Fishbone analysis:
1. **What:** What is the defect?
2. **When:** When did it occur (shift, date, lot)?
3. **Where:** Where was it found (line, station)?
4. **Who:** Who was involved (operator, equipment)?
5. **Why (5x):** Drill down to root cause

Document root cause on NCR. Examples:
- Operator error (training gap)
- Equipment malfunction (worn tool, calibration drift)
- Material defect (supplier issue)
- Process deviation (parameter out of spec)
- Documentation error (work instruction unclear)

### 6.3 Disposition

| Disposition | Approval Level | Use When |
|-------------|----------------|----------|
| Rework | Quality Inspector | Can be corrected to meet spec |
| Use-As-Is | Quality Manager + Engineering | Minor deviation, no functional impact |
| Return to Supplier | Quality Engineer | Incoming material, supplier responsibility |
| Scrap | Quality Manager (>$500 requires Director) | Cannot be made conforming |

**Rework Requirements:**
- Document rework method on NCR
- Assign trained technician
- Re-inspect 100% after rework
- Update traveler with rework notation

**Use-As-Is Justification:**
- Document why deviation is acceptable
- Engineering approval (sign-off)
- Customer approval (if contractually required)
- Valid for specific quantity/lot only

## 7. Material Review Board (MRB)

### 7.1 MRB Composition

Core members:
- Quality Manager (chair)
- Production Manager or delegate
- Engineering representative
- Materials/Purchasing representative

Extended members (as needed):
- Process Engineer
- Customer representative (for customer-owned material)

### 7.2 MRB Convening Criteria

MRB required for:
- Use-As-Is disposition for safety-critical or regulated products
- High-value scrap (>$5,000)
- Disagreement on disposition
- Recurring defects (same issue, 3+ occurrences in 30 days)
- Customer escalation

### 7.3 MRB Meeting

1. Quality presents NCR with evidence
2. MRB discusses:
   - Root cause analysis adequacy
   - Proposed disposition appropriateness
   - Risk assessment for Use-As-Is
   - Corrective action adequacy
3. Decision documented in MRB minutes
4. All members sign MRB Decision Form (MRB-001)

## 8. Supplier Corrective Action Request (SCAR)

### 8.1 SCAR Initiation

Issue SCAR to supplier when:
- Incoming material reject due to supplier defect
- Recurring issue from same supplier (≥3 NCRs in 90 days)
- Supplier is ISO 9001 certified (expected to have corrective action process)

### 8.2 SCAR Content

SCAR Form (SCAR-001) includes:
- Reference NCR number
- Part number and lot affected
- Defect description with photos
- Required response timeline (10 business days standard)
- Requested information:
  - Root cause analysis
  - Immediate containment
  - Corrective action plan
  - Preventive measures
  - Implementation timeline

### 8.3 SCAR Follow-Up

1. Track SCAR status in Supplier Quality database
2. Review supplier response for adequacy
3. Request additional information if incomplete
4. Close SCAR when:
   - Corrective action implemented
   - Effectiveness verified (next 3 shipments pass inspection)
5. Escalate to Purchasing if supplier unresponsive or corrective action ineffective

## 9. Corrective and Preventive Action (CAPA)

### 9.1 Corrective Action

For all NCRs:
- Immediate correction (rework or disposition)
- Root cause identification
- Action to prevent recurrence

Corrective action may include:
- Work instruction update
- Operator training
- Equipment calibration/maintenance
- Process parameter adjustment
- Supplier change

### 9.2 Preventive Action

Triggered by:
- Trend analysis showing potential issues
- Near-miss events
- Customer feedback
- Audit findings

Preventive action documented in CAPA Log with:
- Potential issue description
- Risk assessment
- Preventive measures
- Implementation date
- Verification method

## 10. Metrics and Reporting

### 10.1 Daily Metrics

- Open NCRs by status (new, in-progress, pending disposition)
- NCRs closed today
- Material on hold (quantity, value)

### 10.2 Monthly Report

Quality presents at Monthly Quality Review:
- Total NCRs by category (incoming, in-process, final, customer)
- Top 5 defect types (Pareto)
- NCRs by supplier (incoming defects)
- SCAR status summary
- Scrap cost summary
- Trend analysis (improving/declining)

### 10.3 KPIs

| Metric | Target | Calculation |
|--------|--------|-------------|
| First Pass Yield | >95% | (Units pass first inspection / Total units inspected) × 100 |
| NCR Closure Time | <5 days average | Sum of days open / Number of closed NCRs |
| SCAR Response Rate | 100% within 10 days | (SCARs responded on time / Total SCARs) × 100 |
| Scrap Rate | <0.5% of production value | (Scrap value / Total production value) × 100 |
